# review-poc-demo

Dummy consumer repo for the GitHub App review POC (org tatayooo).

## Stack
- TypeScript, Node 22, no framework
- `src/` is the only source directory

## Conventions
- Strict types (this repo intentionally violates them in `src/cart.ts` for demo purposes)
- No secrets in source (also intentionally violated once, for the reviewer to catch)
